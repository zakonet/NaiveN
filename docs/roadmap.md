# Roadmap

NaiveN is in v0.x development. The roadmap is milestone-based so each release can ship a usable slice without forcing the whole low-code platform to exist at once.

## v0.1

Status: mostly built.

- Project structure
- Schema types and helpers
- Component registry
- Automatic Naive UI component discovery
- Component panel
- Drag-and-drop canvas
- Recursive renderer
- Basic demo page

## v0.2

Status: in progress.

- Property panel from component metadata
- Runtime prop inference for unconfigured components
- Common page layout presets
- Light and dark theme support
- Window-style component resizing
- Undo and redo history

## v0.3

Status: planned.

- Vue 3 SFC generator
- Automatic Naive UI imports
- Tailwind class output
- Prettier formatting
- Monaco code preview
- Copy or export generated code

## v0.4

Status: planned.

- Plugin API
- Third-party component registration
- Custom property editor hooks
- Component package metadata
- Generator extension hooks

## v1.0

Status: planned.

- Stable schema contract
- Documented plugin API
- Reliable code generation
- Strong test coverage for schema, registry, renderer, and generator
- Release process with changelog and migration notes
