# Changelog

All notable changes to NaiveN will be documented in this file.

This project follows Conventional Commits. Release entries should group changes by user impact.

## Unreleased

### Added

- Schema-first page model for components, props, children, styles, and events.
- Automatic Naive UI component registration with lazy loading.
- Drag-and-drop component palette and sortable canvas.
- Recursive renderer for schema nodes.
- Inspector for editing text nodes, component props, scale, and node size.
- Light and dark theme switching.
- Page structure presets for layout, top bar, tabs, menu, and page header.

### Changed

- Dark theme uses a Chrome-like gray palette.

### Planned

- Vue SFC code generation.
- Monaco-based code preview.
- Plugin API for third-party component registration.
