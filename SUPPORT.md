# Support

NaiveN is an open source project. Support is best-effort unless the project owner defines another support channel.

For project-level questions that do not fit a public issue, email `contact@zako.net.cn`.

## Before asking for help

Please check:

- The README for setup and architecture notes.
- Existing issues for similar reports.
- The current branch builds with `npm run build`.

## Good support requests

Include:

- What you were trying to do.
- What happened instead.
- Steps to reproduce the problem.
- Browser and operating system.
- Relevant console errors or screenshots.

For security problems, follow `SECURITY.md` instead of opening a public issue.
